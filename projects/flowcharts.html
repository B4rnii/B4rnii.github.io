FlowCharts

A trading chart analysis tool developed from scratch.


Dependencies

  • raylib: Rendering, Audio.
  • rlImGui: raylib backend implementation for Dear ImGui.
  • Dear ImGui: UI overlays and interactions.
  • nlohmann/json: Handling TradeLocker's JSON data responses.
  • TradeLocker: Real-time data.
